## 部署环境事实（kumiko-design）
- 远程仓库：`https://github.com/salenju/kumiko-design.git`，**public**，主分支 `main`。
- 预期站点：`https://salenju.github.io/kumiko-design/`（CI 经 configure-pages 自动得到 base_path，无需手填）。
- **必须先在仓库 Settings → Pages → Source 选 "GitHub Actions"**：否则 `actions/configure-pages@v5` 在 Pages 未启用时 `GET /repos/{owner}/{repo}/pages` 返回 404 直接失败（`enablement` 默认 false，自动启用需管理员 PAT，不建议）。
- Custom domain 留空即可（可选，仅用于绑定自有域名）；`Enforce HTTPS` 保持勾选；`Visibility` 是 GitHub Enterprise 功能，忽略。
- ⚠️ 若日后改为自定义域名：**origin 变化会导致浏览器本地工作区数据（IndexedDB）读不到**，PWA 也需重新安装 → 迁移前务必先「备份全部」导出 zip。
