# 组子细工绘图助手 - 技术开发方案

## 1. 项目概述
开发一款面向“组子细工”爱好者的 **2D 平面绘图与算料工具**。核心价值在于：让用户通过绘制线条快速搭建组子图案，并能一键查看每根线条的精确尺寸、调整间距与宽度，最终为后续裁切提供数据支持。

## 2. 核心功能需求（PRD）
1. **线条与尺寸的增删改查**
   - **增**：在画布上通过鼠标点击/拖拽添加新线条。
   - **删**：选中线条后按键盘 Delete 或点击删除按钮。
   - **改**：选中线条后在属性面板修改其起点/终点坐标、线宽等。
   - **查**：支持点击选中、框选，并在属性面板显示当前选中线条的详细信息。
2. **自动计算各线条尺寸**
   - 每条线实时显示长度（精确到 0.1mm，基于坐标勾股定理计算）。
   - 支持显示多条线之间的间距（平行线垂直距离）。
3. **纯 2D 平面绘图**
   - 不需要 3D 视图，所有操作在二维画布上完成。
4. **调整线条间距与宽度**
   - **间距调整**：选中多条线后，可通过输入数值或拖动手柄统一调整间距（水平/垂直等距分布）。
   - **宽度设置**：每条线可独立设置描边宽度（strokeWidth），并在画布上实时反映。

## 3. 技术选型（纯 JavaScript，无 TypeScript）
| 类别 | 技术方案 | 说明 |
|------|----------|------|
| 构建工具 | **Vite** | 快速启动，原生支持 Vue 3 和 Worker。 |
| 前端框架 | **Vue 3 + `<script setup>`** | 使用组合式 API（Composables）组织逻辑。 |
| 状态管理 | **Pinia** + `pinia-plugin-persistedstate` | 管理画布数据（线条数组、选中状态），自动保存至 localStorage。 |
| UI 组件库 | **Naive UI**（或 shadcn-vue） | 提供属性面板、输入框、按钮等，专业且轻量。 |
| 画布渲染 | **vue-konva** + Konva | 基于 2D Canvas，提供面向对象的图形操作。 |
| 几何计算 | **@flatten-js/core** | 纯 JS 几何库，用于求长度、距离、交点等。 |
| 性能优化（可选） | **Comlink** + Web Worker | 将复杂排版计算移至 Worker，保证 UI 流畅。 |
| 排版优化（可选） | **rectangle-packer** | 用于自动排样（计算材料利用率）。 |
| AI 功能（可选） | VueUse 的 `useFetch` + 大模型 API | 自然语言生成预设纹样（如“生成 30cm 麻叶纹”）。 |

## 5. 核心实现要点（给 AI 的编码指引）

### 5.1 数据模型（Pinia state）
```javascript
// stores/project.js
state: () => ({
  lines: [
    {
      id: 'unique_id',
      x1: 10, y1: 20, x2: 100, y2: 200, // 起点终点坐标
      strokeWidth: 2,                   // 线宽（默认2px）
      selected: false
    }
  ],
  selectedIds: [],          // 支持多选
  materialWidth: 1200,      // 板材宽（用于算料）
  materialHeight: 2400      // 板材高
})
```

### 5.2 尺寸计算（纯函数）
- 线长度：Math.hypot(x2 - x1, y2 - y1)
- 两线间距：若两线平行，使用点到直线距离公式；否则求交点并计算最短距离。
- 所有计算放在 core/geometry/ 目录，方便复用和测试。

### 5.3 交互流程
- 绘制线条：点击“画线”工具 → 在画布上点击起点 → 拖拽至终点松手 → 生成线条并存储。
- 选择/取消选择：点击线条切换选中状态（支持 Shift 多选），点击空白取消全部选中。
- 修改属性：选中线条后，右侧面板显示坐标和线宽输入框，修改后立即更新画布。
- 调整间距：选中多条线，点击“垂直等距”或“水平等距”按钮，程序自动计算平均间距并重新排列。

### 5.4 性能注意事项
- 避免响应式陷阱：Pinia 中只存纯数值（如坐标数组），不要存储 @flatten-js 的对象实例（它们有方法，Vue 代理可能导致异常）。在需要时再实例化几何对象。
- 大项目优化：若线条超过 200 条，考虑将计算（如批量求交点）放入 Web Worker（使用 Comlink 简化通信）。
- 防抖：属性修改输入框建议使用 @vueuse/core 的 useDebounceFn 减少频繁渲染。

6. 开发阶段（MVP 路线图）
- Phase 1（核心闭环）：搭建 Vite + Vue 3 + vue-konva，实现画布显示、画线、选中、删除，并在右侧显示选中线的长度和线宽输入框。
- Phase 2（增强交互）：实现多选、框选、批量删除，添加“等距分布”功能，完成间距调整。
- Phase 3（算料导出）：集成 rectangle-packer，点击“算料”按钮生成切割布局图，并显示总长度、利用率等。
- Phase 4（AI 辅助）：接入大模型 API，实现自然语言生成纹样（可选）。
- Phase 5（桌面打包）：使用 Tauri 将 Web 应用打包成 Mac/Windows 桌面应用（可选）。


## 7. 常见陷阱与解决方案（重要）
陷阱	解决方案
将几何对象（如 @flatten-js 的 Point）存入 Pinia，导致响应式异常	只存 {x, y} 或数组，计算时再创建几何对象。
Konva 的事件系统中 e.target 与 Vue 响应式混杂	将 Konva 事件与 Vue 状态通过 useCanvas 隔离，只传递纯数据。
Worker 中无法使用 Vue 或 DOM API	确保 Worker 脚本只引用纯 JS 模块，不导入 Vue 相关包。
画布频繁重绘导致卡顿	使用 Konva 的 batchDraw() 批量更新，或使用 throttle 限制重绘频率。
