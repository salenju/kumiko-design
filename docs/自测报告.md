## 5. 关键实现验证点（对照 V2 要点）

- **派生不入 store**：`project.segments` 是 getter 响应式派生（依赖 patterns 引用，变化才重算），state 仅存纯数据 → smoke.spec 快照往返后段数一致。
- **撤销粒度**：beginEdit（单动作）与属性面板「focus 记起点 / change 有变化才入栈」两种模式并存，undo/redo 在集成测试中多次往返验证。
- **单位语义**：全链路 mm——stroke-width=物理 mm（PatternLayer.spec 断言 stroke-width="3"/"4"），SVG 导出带 mm 尺寸与 viewBox；交互用 viewBox 屏幕↔世界换算（冒烟中 viewBox 实测有效）。
- **渲染性能**：395→790→1342 段下 DOM 操作正常；更大量级（数千段）的 Worker 化延后符合 V2 §2 决策。
