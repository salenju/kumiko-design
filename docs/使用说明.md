# 组子细工绘图助手 · 使用说明

本文档面向第一次运行本工具的用户：从启动到完成一次「画图 → 编辑 → 算料 → 导出」的完整流程，并附所有按钮/快捷键/参数解释。

---

## 1. 启动与界面

```bash
cd kumiko-design/kumiko-design   # 项目根目录（含 package.json）
pnpm install                     # 首次运行：安装依赖
pnpm dev                         # 启动开发服务器
```

浏览器打开 http://127.0.0.1:5173/ 即可。界面分三块：

```
┌──────────────────────────── 工具栏 ────────────────────────────┐
│ [选择][画线族][画单线][平移] | [撤销][重做][复制][删除选中]     │
│ [＋预设纹样][✦AI生成] | [⊞网格][尺标注][⤢适配]                  │
│ [🗂工作区][＋新建][💾保存][⇩导出文件][⇧导入文件][⚙设置]         │
│ …… [✔导出施工][🔩图案部件][📏算料][⬇导出SVG]                    │
│              状态栏：[作品名] · N 图案 · M 段 · 保存中…          │
├───────────────────────────────────────┬────────────────────────┤
│                                       │  右侧属性面板           │
│          SVG 画布（mm 世界坐标）        │  （选中后编辑线族参数）  │
│                                       │                        │
└───────────────────────────────────────┴────────────────────────┘
```

画布背景为 **mm 网格**（深灰 = 主轴），图案由「木条」组成，**线宽即真实木条宽度**（1mm 数据 = 1mm 物理宽度 × 缩放显示）。

## 2. 快速上手（5 分钟完整流程）

### 第 1 步：添加一个预设纹样
点工具栏 **「＋ 预设纹样」**，弹窗内：
- **纹样**：麻叶纹（三组互成 60° 的正三角网格）／方格纹（正交两族）／斜格纹（45° 菱形）
- **外框尺寸 mm**：整幅图案的边长（默认 300）
- **间距 mm**：相邻木条的中心距（改小图案更密）
- **木条宽 mm**：木条实际宽度
- **中心 X / Y mm**：图案中心放在画布哪个坐标（默认 0,0 = 画布中心）

点 **「添加到画布」** → 图案立即渲染为大量交叉线段，状态栏显示「3 线族 · N 段」。

### 第 2 步：查看/选择
- **鼠标悬停**任一线段 → 显示该段长度（mm，0.1 精度）；标注自动避开线段：横线标在上方、竖线标在左侧、斜线标在侧旁。
- **按住拖拽线段**：移动它——单线自由平移，线族整体平移；拖动时实时显示该线与最近相邻平行线的垂直间距。拖完后可用 Ctrl+Z 撤销。
- 选中单线后，右侧面板可用「**相邻线间距**」下拉框把它调到与相邻平行线的目标间距：下拉值为**全局间距单位的整数倍**（如 4x = 4 × 10mm = 40mm，默认单位 10mm，见「设置 → 全局间距单位」）。**基准规则**：横线以**上方**相邻平行线为基准，竖线以**左侧**相邻平行线为基准（标签与提示会写明）；拖动时若被拖线与相邻线的间距恰好与相邻两参考线的间距一致，会高亮提示「间距与相邻线一致」。
- **单击**线段 → 选中它所属的整族线（变蓝），右侧出现该族属性卡，显示「该族派生 X 段 · 长 Y mm」。
- **按住鼠标左键拖出框** → 框选（选中框内所有线段所属的线族）。
- **Ctrl/⌘ + 单击** 或 **Shift + 单击** → 加选/取消单个线族。
- 点画布空白 → 取消选择。

### 第 3 步：编辑参数（核心操作）
选中后，在右侧属性面板修改，**画布实时重排**：
| 参数 | 含义 | 提示 |
|------|------|------|
| 角度 ° | 线族方向 | 步进 15°；0=水平、90=竖直 |
| 间距（Nx） | 相邻木条中心距 = N × 全局间距单位（默认 1x = 10mm） | 下拉选 1x–8x（间距超出自动扩展）；**想整体调密/调疏就改它**（等同“等距分布”） |
| 条数 | 该族平行线条数 | 越多越密 |
| 木条宽 mm | 木条物理宽度 | 影响视觉效果与算料 |
| bounds X/Y/宽/高 | 该族绘制范围矩形 | 超出范围的部分会被裁掉，改宽/高可放大图案 |

> 每次编辑在**失焦（点别处）或按回车时记录一步撤销**：连续改动一次角度算一步，可 Ctrl+Z 逐步回退。

### 第 3.5 步：画单根线
点工具栏 **「画单线」**（或按数字键 **3**），在画布上**点住拖拽**：松开即生成一根独立线段（自动吸附网格，长度会实时显示）。
- 单线不参与线族求交，作为独立木条参与算料/导出；
- 点选该线后在右侧面板可编辑 **起点 X1/Y1、终点 X2/Y2、木条宽**，Delete 或「🗑」删除；
- 想删除画面上某根单独的线：点中它 → 删除选中即可；线族中的线通过调「条数」增减。

### 第 3.6 步：设置（⚙）与 Pad/触屏
- 工具栏 **「⚙ 设置」**（位于文件区末）：
  - **全局间距单位**：组子布排的基本单位（默认 10mm，原位于算料抽屉）——线族「间距」与单线「相邻线间距」都按它的 **Nx 整数倍**设置；改单位不影响已画线段的实际间距。
  - **线条颜色（按方向角度）**：线族与单线按其方向角度取色（0°/90°/45°/60°… 可分别设置，也可**新增任意角度**、删除或恢复默认）；未单独设置的角度用「其它角度」兜底色。**悬停高亮色**（鼠标移到线段）与**选中高亮色**也可单独修改，避免与线条本身颜色相近冲突。颜色随项目保存/可撤销，并作用于画布、导出 SVG 与施工包设计图。
- **Pad / 触屏（iPad、安卓平板）**：
  - 单指：画线族/画单线/点选/拖拽移动/框选 均可直接操作；
  - **双指捏合** = 缩放（以两指中点为锚点），**双指拖动** = 平移画布；
  - **双击** = 适配视图到图案；
  - 触摸点选容差更大、有过小的拖动不误触（防误触处理）；
  - 触摸屏**没有悬停**，所以「鼠标移上去显示该段长度」在平板上不可用 → 请用工具栏 **「尺 标注」** 开关显示全部尺寸（打开后每段长度常驻显示）；
  - 工具栏按钮、工作区列表按钮在触屏设备上会自动放大到 **≥ 44px** 的可点区域；常用操作均有按钮（撤销/重做/复制/删除/保存/工作区…），不依赖键盘；
  - 建议**横屏**使用：画布与右侧属性面板并排显示，操作更顺。

### 第 4 步：手动画一族线
1. 点工具栏 **「画线族」**（或按数字键 2）；
2. 在画布**点住拖拽**：从起点拉出方向，蓝色虚线矩形 = 将生成的范围，旁边显示当前角度（自动吸附 15° 步进）；
3. 松开 → 生成一族平行线（默认间距 = 1 × 全局间距单位，默认 10mm；木条宽 3mm）并自动选中；
4. 去右侧面板用「间距（Nx）」下拉细调 间距/条数/角度/bounds。
> 拖得太短（<15mm）会被当作误点忽略；拖拽中按 Esc 取消。

### 第 5 步：算料（切割清单）
1. 点工具栏 **「📏 算料」**，右侧滑出算料抽屉；
2. 设置材料参数：
   - **标准条长 mm**：你购买的木条长度（默认 1200）
   - **锯缝 kerf mm**：每刀损耗（默认 1.5）
   - **端部余量 mm**：每端斜切等预留（默认 2）
   > 全局间距单位与线条颜色不在此处，请在工具栏 **「⚙ 设置」** 中调整。
3. 面板自动按 **木条宽度分组** 给出每组的 cut list 表：
   - 每根标准条装哪几段（`长度×数量`）、使用长度、余料；
   - 汇总：需几根标准条、总用料、**综合利用率 %**。
4. 参数改动即时重算，改材料参数也是一步可撤销操作。

### 第 5.5 步：图案部件统计（施工前同型分组）
组子正式施工前，除切料外还要知道**每种"整根本条"要做多少根**。点工具栏 **「🔩 图案部件」**，右侧滑出与「算料」平行的部件抽屉（两者互斥打开）：

- **部件** = 画布里的一整根木条：线族中每根直线（裁剪到自身范围）以及画出的每根「单线」；
- **插口** = 该木条与其它**非平行**木条（不区分线族/单线、任意角度，如 90°/60°/45°）在实体内相交的交叉点；一根木条两头戳在其他木条端点上不算插口；
- **间距缩写** = 相邻插口中心距 ÷ 全局间距单位后四舍五入取整 x，用 `-` 连接（如 `1-2-1` 表示间距依次 1x、2x、1x；木条翻转视为同型）；
- **同型分组** = 长×宽相同 + 间距缩写相同 + 插口数量相同 → 归为一组标注。

每行显示 `尺寸（长×宽）｜间距缩写｜数量｜插口数`，例如方格纹内区 9 个交叉口的木条组会显示：
`200×3 | 2-2-2-2-2-2-2-2 | 18 piece | 9 插口`
（间距 20mm、全局单位 10mm → 每段 2x）。顶部汇总给出「共几组同型部件 · 共几根本条 · 合计几个插口」。

### 第 6 步：导出
- 点 **「⬇ 导出 SVG」** → 下载 `kumiko-design.svg`。文件坐标是 **真实 mm**，可直接用于矢量软件、激光切割/CNC 排版或打印模板。
- 若提示「画布为空」则先添加图案。

---

### 第 7 步：工作区（多作品暂存 / 恢复）
点工具栏 **「🗂 工作区」**（或点状态栏左侧的作品名）打开工作区抽屉：

- **作品列表**：缩略图 + 名称 + 更新时间 + 图案数 + 占用大小；点「打开」即切换到该作品继续编辑；
- **＋ 新建**：新建一份空白作品（材料参数、间距单位、线条配色沿用当前值；撤销历史清空）；
- **重命名 / 复制 / 删除**：删除会进「回收站」，可在回收站里恢复、彻底删除或清空回收站（均有二次确认）；
- **搜索**：按名称过滤；顶部「作品 / 回收站」两个视图切换；
- **⇧ 导入**：选择 `.kumiko.json`（**支持多选**）→ 每个文件作为一个**新作品**导入（文件名即作品名，重名自动加序号），并自动打开最后一个；
- **导出**（列表项）：把该作品导出为 `<名称>.kumiko.json`；
- **⇩ 备份全部**：把全部作品导出为一个 zip（内含 `manifest.json` + 每作品一个 `.kumiko.json`），**建议定期备份**；
- **容量**：抽屉底部显示已用容量 / 配额与进度条，接近上限会提示；
- **持久化存储**：可点「申请持久化存储」，降低被系统清理数据的风险（未授权时会提示需定期备份）。

**自动暂存**：编辑画布后约 0.4 秒自动写回当前作品，无需手动保存；**💾 保存**（或 **Ctrl/⌘ + S**）可立即暂存。

**旧数据迁移**：首次打开本版本时，之前保存在浏览器里的单项目会自动迁入为第一个作品「我的作品」，不会丢失。

> 数据保存在**浏览器本地**（IndexedDB，兼容模式下退化为 localStorage），**不会上传服务器**。清除浏览器站点数据或卸载应用会一并删除，请用「⇩ 备份全部」留档。

### 第 7.5 步：其他文件操作
- **⇩ 导出文件**：先弹窗**输入导出文件名**，再下载 `<名称>.kumiko.json`（扩展名自动补全，无需手输），可长期备份/发给别人；
- **⇧ 导入文件**：等同工作区内的「导入」（作为新作品导入并打开，不覆盖当前作品）；
- **✔ 导出施工**（绿色成功按钮）：先弹窗**输入压缩包名称**，再下载 `<名称>.zip` 施工资料包，内含：
  1. `<名称>.json` —— 项目文件（**与压缩包同名**，可再导入）；
  2. `<名称>-设计图.svg` —— 真实 mm 矢量设计图；
  3. `<名称>-施工单.html` —— 材料参数 + 算料明细（每根标准料的装载切割）+ 图案部件统计 + 内嵌设计图，浏览器打开即看、可直接打印/另存 PDF；
  4. `<名称>-算料.csv`、`<名称>-图案部件.csv` —— 机器可读，便于 Excel 等二次加工。

### 第 8 步：安装到主屏（PWA）与离线使用
本应用是 PWA（渐进式 Web 应用），可像 App 一样安装到 Android 平板主屏，**断网也能完整使用**：

1. 用 **Android Chrome** 打开部署地址（必须是 **HTTPS**，如 GitHub Pages 提供的地址）；
2. 顶部出现「安装到主屏」提示条 → 点 **安装到主屏**；也可以从 Chrome 菜单选「安装应用 / 添加到主屏幕」；
3. 安装后从主屏图标打开，为**独立窗口**（无地址栏），支持横竖屏；
4. 首次打开后资源会被预缓存 → **开飞行模式也能冷启动**、继续编辑、导出（导出走本地下载，不依赖网络）；
5. 应用更新时会提示「发现新版本」→ 点 **立即刷新** 即可升级，**本地作品数据不会丢失**。

> 目录选择类能力（File System Access API）在 Android Chrome 上不可用，因此本应用采用**应用内工作区 + 导入导出**方案，不直接读写平板任意目录。

## 4. 关于「AI 生成」（可选）
点 **「✦ AI 生成」**，输入自然语言，例如：
- `生成一个 30cm 的麻叶纹`
- `做一个 200mm 的方格纹样`
- `给我一个 45 度的菱形斜格纹`

点击 **「解析意图」** 会先显示识别结果（纹样类型 + 尺寸），确认后点 **「添加到画布」**。
> 当前版本是**本地规则解析**（无需联网/密钥）：能识别 麻叶/方格/斜格 及 cm/mm 尺寸，几何始终由内置参数化生成器产出，保证精确。未来接入大模型后交互不变。

## 5. 常见问题

**Q：图案看起来是“碎成一段段”的？**
A：正常。组子工艺里木条在交叉点被切开成独立段，画布显示的就是实际木条段；每段长度、数量正是算料依据。

**Q：想整体调密/调疏怎么最快？**
A：选中任一方向的线族，在右侧面板用「间距」下拉改倍数（Nx = N × 全局间距单位）。每个方向（族）要分别选中调整——麻叶纹有 3 个方向、方格/斜格有 2 个。

**Q：只看到半截线条，边界外消失了？**
A：bounds（绘制范围）限定了该族的裁剪区域。在属性面板把 bounds 的宽/高调大，或把 X/Y 移到想要的位置。

**Q：改角度/间距后段数变化很大？**
A：预期行为——线条方向和疏密变了，与其他族的交点数量随之改变，派生段数自然变化。

**Q：关闭页面后图会丢吗？**
A：不会。作品数据自动暂存到浏览器本地（IndexedDB，画布变化后约 0.4 秒写入），重新打开会回到上次编辑的作品。支持同时保存多个作品，在「🗂 工作区」里切换。**清除浏览器站点数据或卸载 PWA 会一并删除**，请用「⇩ 备份全部」定期留档。

**Q：换设备 / 换浏览器能看到我的作品吗？**
A：默认不能。数据只存在本机浏览器里，不联网、不上传。跨设备请用「⇩ 备份全部」导出 zip，在新设备用「⇧ 导入」逐个（可多选）导入。

**Q：平板上的「工作区」为什么不是直接读写我平板的文件夹？**
A：Android Chrome 不支持目录选择 API（File System Access API），网页无法直接读写任意目录。因此本应用把作品存在应用内工作区，并提供「导出 → 系统下载目录 / 导入 ← 系统文件选择器」两条通道，效果等价且更安全。

**Q：桌面窗口太大/太小怎么办？**
A：滚轮缩放、拖动平移、「⤢ 适配」一键回到全景。

**Q：能直接用于激光切割吗？**
A：导出的 SVG 使用真实 mm 坐标与真实线宽，适合作为矢量输入；但端部是否斜接/燕尾、切割顺序等工艺参数请按你的设备与工艺在切割软件里设置。

## 6. 常用开发命令

```bash
pnpm dev        # 开发服务器（不注册 Service Worker，避免缓存干扰热更新）
pnpm test       # 全部自动测试（core 几何/间距/派生/下料 + AI 解析 + 渲染 + 工作区 + 集成冒烟）
pnpm build      # 生产构建到 dist/（生成 manifest.webmanifest + sw.js）
pnpm preview    # 预览生产构建（离线/PWA 请用这里验证，而非 pnpm dev）
pnpm pwa:assets # 由 public/logo.svg 重新生成 PWA 图标集（改了图标才需要跑）
```

**子路径部署（GitHub Pages）**：构建时传入 `BASE_PATH`，它会同时作用于 Vite base、PWA `start_url`/`scope`：

```bash
BASE_PATH=/<你的仓库名>/ pnpm build
```

> 注意：若部署在子路径却用根路径构建，会出现白屏或 Service Worker 注册失败。

**CI 部署**：推送 `main` 分支后由 `.github/workflows/deploy.yml` 自动执行「安装 → 测试 → 构建 → 发布 Pages」。需在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**（免费版需 public 仓库）。
